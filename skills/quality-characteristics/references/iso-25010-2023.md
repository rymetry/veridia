# ISO/IEC 25010:2023 Product Quality Model 詳細

> 注意: 本ファイルは2023年版の一般的な整理として記載している。規格本文(有償)との
> 突き合わせは未実施。副特性の名称・構成を根拠として外部に示す場合は一次資料で確認すること。

## 9特性と副特性

| 特性 | 副特性 | 問い(対話での使い方) |
|---|---|---|
| Functional Suitability(機能適合性) | 完全性 / 正確性 / 適切性 | 業務に必要な機能が揃い、正しく、目的に合っているか |
| Performance Efficiency(性能効率性) | 時間効率性 / 資源効率性 / 容量満足性 | 応答は速いか、資源を食いすぎないか、量に耐えるか |
| Compatibility(互換性) | 共存性 / 相互運用性 | 他システムと同居できるか、正しくデータ交換できるか |
| Interaction Capability(インタラクション容易性) | 認識性 / 習得性 / 操作性 / ユーザーエラー防止 / エンゲージメント / 包摂性 / ユーザー支援 / 自己記述性 | 迷わず使えるか、間違えにくいか、誰でも使えるか |
| Reliability(信頼性) | 無障害性 / 可用性 / 障害許容性 / 回復性 | 壊れないか、壊れても検出・縮退・回復できるか |
| Security(セキュリティ) | 機密性 / インテグリティ / 否認防止 / 責任追跡性 / 真正性 / 抵抗性 | 守るべきものが守られ、攻撃に耐えるか |
| Maintainability(保守性) | モジュール性 / 再利用性 / 解析性 / 修正性 / 試験性 | 原因を調べやすく、直しやすく、テストしやすいか |
| Flexibility(柔軟性) | 適応性 / 設置性 / 置換性 / 拡張性 | 環境・規模の変化に追従できるか |
| Safety(安全性) | 運用制約 / リスク特定 / フェールセーフ / 危険警告 / 安全統合 | 人・環境への危害につながる経路がないか |

## 2011年版からの主な変更

```text
Usability      → Interaction Capability(副特性も再編。包摂性などが追加)
Portability    → Flexibility(拡張性が追加)
Reliability    成熟性(maturity) → 無障害性(faultlessness)へ改称
Security       抵抗性(resistance)が追加
Safety         特性として新設(2011年版には存在しない)
```

生成モデルの学習データには2011年版の語彙が多い。`Usability` / `Portability` が
出力されたら版の取り違えを疑う。

## 使い方の注意

- このモデルは**選択のための参照フレーム**であり、チェックリストではない
- 副特性まで降りるのは、特性の議論が曖昧になったときだけ
  (例:「信頼性が大事」で止まったら「障害許容と回復性のどちらの話か」と問う)
